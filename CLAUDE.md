# Muse Gadget SDK: DCDominguez fork

Firmware is in `esp32/` (start with `esp32/AGENTS.md`). The M5Stack Tab5 port
and its docs are in `tab5/` (`tab5/README.md`).

If a Tab5 is plugged into this machine, read `tab5/BRIDGE.md` before touching
it: it holds the owner's rules for flashing, secrets and the serial console.
Never open `tab5-sdk-token.txt`, `tab5-elevenlabs-key.txt` or
`%USERPROFILE%\tab5-secrets\`.
